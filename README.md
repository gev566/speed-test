# Замер скорости интернета

Консольный скрипт на Python. Делает 10 запросов подряд к указанному адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

Python 3.9 или новее. Сторонние библиотеки не нужны — используется только стандартная библиотека.

## Запуск

```bash
python3 speedtest.py <адрес>
```

На Windows команда может называться `python` вместо `python3`.

Пример:

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Необязательные параметры:

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `-n`, `--count` | число запросов | 10 |
| `-t`, `--timeout` | таймаут одного запроса, секунды | 30 |

## Пример вывода

```
Запрос  1: 2.478 с, 10.49 МБ
Запрос  2: 2.086 с, 10.49 МБ
...
Запрос 10: 2.098 с, 10.49 МБ

Запросов:              10
Среднее время запроса: 2.221 с
Скачано всего:         104.86 МБ (104857600 байт)
Скорость скачивания:   37.77 Мбит/с (4.72 МБ/с)
```

## Единицы измерения

- **Время** — секунды.
- **Объём** — мегабайты, 1 МБ = 1 000 000 байт.
- **Скорость** — мегабиты в секунду (Мбит/с), как у провайдеров и на speedtest-сервисах; в скобках то же значение в МБ/с. 1 байт = 8 бит, 1 Мбит = 1 000 000 бит.

## Как считается

- Запросы идут строго по очереди: следующий начинается после полного получения предыдущего ответа.
- Время запроса — от отправки до последнего прочитанного байта тела ответа, то есть включает установку соединения и ожидание сервера.
- Среднее время = сумма времён / число запросов.
- Скорость = общий объём / общее время.
- Объём считается по реально прочитанным байтам тела ответа, а не по заголовку `Content-Length`.

## Ограничения

- Результат зависит не только от канала, но и от сервера: если он медленный или далеко, скорость будет ниже реальной.
- Небольшой файл даёт заниженную скорость, потому что заметную часть времени занимает установка соединения. Лучше брать файл от нескольких мегабайт.
- Некоторые сайты ограничивают частые скачивания одного файла и отвечают ошибкой 429. Для замера лучше брать адрес, предназначенный для тестов скорости, как в примере выше.
- Если любой запрос завершился ошибкой, скрипт останавливается с кодом выхода 1.
